# Review receipts

Every PR adds a review report here (`reviews/<branch-or-topic>.md`), written by the author's own agent running the BCQuality Review locally. The **Review receipt** check fails without one, or when it has open blockers.

Report format: see `AGENTS.md` in https://github.com/JeremyVyska/directions-emea-2026-workshop (section "Review report contract").
